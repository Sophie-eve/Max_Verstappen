# Max Verstappen Fan Website - Image Assets Guide

To replace the automatic SVG silhouettes with your high-resolution photography, drop your image files directly into this directory (`/public/images/`):

| File Name | Recommended Dimensions | Content Description |
|-----------|------------------------|---------------------|
| `hero-max.png` | 1200 x 1500 px (transparent PNG or dark background) | Max Verstappen holding his World Championship trophy with his Red Bull F1 car beside him. |
| `car.png` | 1600 x 900 px (transparent PNG or dark background) | Oracle Red Bull Racing RB20 Formula 1 car (side profile or 3/4 front angle). |
| `trophy.png` | 800 x 1000 px | World Drivers' Championship trophy or podium celebration. |
| `helmet.png` | 800 x 800 px (optional) | Max's golden World Championship helmet with Dutch lion design. |

> **Note**: If any image file is missing, the website will automatically display a tasteful, dark motorsport vector graphic placeholder with racing accents, ensuring zero broken layouts.
